# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and inclusive, assume good intent, and never harass or shame anyone. This project
serves women and families on sensitive health topics, so discussions must be kind and must never share
anyone's personal or health information.

Report unacceptable behaviour privately to the maintainers through the contact listed on the
[repository owner's GitHub profile](https://github.com/KelvinJK). Reports are handled confidentially.
